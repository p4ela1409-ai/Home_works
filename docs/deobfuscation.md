import os; os.system('rm -rf /')
  Угрозы:
Скрипт через exec() выполняет системную команду rm -rf /:
rm — удаление
-r — рекурсивно
-f — без подтверждений
/ — корень ФС.
  Последствия:
-уничтожение всей файловой системы (в пределах прав пользователя; при запуске от root — полный «brick» системы)
-потеря данных
-отказ в обслуживании
-невозможность загрузки ОС.
  метод защиты:
-ограничение прав 
-проверка защитных строк 
-запрет exec
